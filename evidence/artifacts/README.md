# Generated artifacts

This directory contains curated outputs that are useful for demonstrations or
historical inspection but are not application source code.

- `demo-assets/`: generated product screenshots. Forecast assets use real
  aggregate AAR data; trip-level scheduling assets use the fictional reference
  agency and must remain labeled synthetic.
- `knowledge-graph/<date>/`: dated Graphify snapshot. It describes the repository
  as it existed on that date and may contain paths that have since moved.

Scratch caches and automated audit outputs are ignored. New generated material
should be dated or reproducible and should not return to the repository root.
