## Important interpretation note

Hardware acceleration changes constants, parallelism, memory traffic and the practical size of solvable instances. It does not convert general NP-complete problems into polynomial-time problems. The dossier therefore distinguishes exact polynomial workloads, approximate/probabilistic workloads, exact exponential search, structured parameterised methods and heuristic optimisation.
