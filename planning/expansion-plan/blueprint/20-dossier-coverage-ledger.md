# Dossier coverage ledger

## Purpose

This ledger makes the dossier-to-blueprint translation auditable. Every one of
the 80 software-to-silicon technologies and 72 intelligence-layer projects has
a Milexium landing point.

Program letters reference the parallel roadmap:

- **A** canonical substrate
- **B** Connect
- **C** MilexiumDB/semantic state
- **D** Core/adaptive memory
- **E** Forecast
- **F** Decide
- **G** Verify/formal knowledge
- **H** Replay/simulation/world models
- **I** Explain/evidence/experience
- **J** Experience Fabric/Forge
- **K** hardware-aware Runtime
- **L** confidential/private/edge
- **M** APIs/ecosystem/commercial surfaces

## Interpretation

“Integrated” does not mean copying all upstream repositories into one product.
It means each research result has:

- a named Milexium capability;
- a stable interface or transferable design pattern;
- an evaluator and reference baseline;
- an artifact/version/provenance contract;
- a place in the experience loop;
- a software and, where applicable, hardware lowering path.

This ledger is the checklist used by swarm orchestration and architecture review.
